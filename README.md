# NHQM Media Downloader — MP3 & MP4 Download Tool

**NHQM Media Downloader** is a Python-based media downloading utility designed to simplify downloading and converting online videos into high-quality audio and video files.

The tool provides an interactive Windows command-line interface (CLI), allowing users to download media directly from supported URLs, including YouTube, with a simple and efficient process.

Users can choose between **MP3 audio** and **MP4 video**, with support for Full HD (1080p) video downloads when available.

### Key Features

- Download videos from supported online platforms.
- Convert video content into MP3 audio files.
- Download MP4 videos in Full HD (1080p).
- Automatically save downloaded files to the Windows desktop.
- Display real-time download progress and speed.
- Automatically merge video and audio streams when required.
- Custom NHQM terminal interface with ASCII styling.
- Simple URL input and format selection.
- Support for high-quality audio extraction.

**Technologies:** Python, Windows CMD, yt-dlp, FFmpeg, Media Processing, CLI Development.

**Project Goal:** To provide a lightweight, reliable, and user-friendly media downloading solution that simplifies audio extraction, video downloading, and file management through a streamlined command-line experience.
